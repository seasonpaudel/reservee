# 🍽️ Reservé – Online Restaurant Table Reservation System  

## 📖 Overview  
**Reservé** is a web-based restaurant table and menu reservation system developed for academic purposes as part of the **Bachelor of Computer Engineering (Pokhara University, 2023)**.  
It enables customers to explore restaurants, view menus, and reserve tables online, while restaurant administrators can efficiently manage bookings, approve requests, and update restaurant information from an integrated dashboard.  

---

## ⚙️ Key Features  

### 👤 Customer Dashboard  
- Register and log in securely.  
- Browse available restaurants and explore menus.  
- Reserve tables based on date, time, and number of guests.  
- View, modify, or cancel reservations easily.  

### 🧾 Admin Dashboard  
- Manage and verify reservation requests.  
- Add, edit, or remove restaurant menus and details.  
- View daily and upcoming bookings through a clean interface.  

### 🔄 Reservation Flow  
- Real-time table availability check.  
- Instant confirmation of successful bookings.  
- Notification for booking status and updates.  

### 💾 Data Management  
- All reservation data stored securely in a **MySQL** database.  
- Different access levels for admin and users to ensure data integrity.  

---

## 🧠 Tech Stack  
**Frontend:** HTML, CSS, Bootstrap, JavaScript  
**Backend:** PHP  
**Database:** MySQL  
**Development Tools:** Visual Studio Code, XAMPP (Localhost)  

---

## 🏗️ System Architecture  
1. **Frontend (Client Side):** Handles customer interaction, displaying restaurant and menu details.  
2. **Backend (Server Side):** PHP scripts process user requests, manage authentication, and communicate with the database.  
3. **Database (MySQL):** Stores users, restaurants, menus, and reservation records.  
4. **Admin Panel:** Manages reservations, menu items, and restaurant data efficiently.  

---

## 🔒 Security & Validation  
- Login authentication for both users and admins.  
- Validation of user input and booking details to prevent duplicate entries.  
- Restricted access to admin dashboard ensuring data privacy and integrity.  

---

## 🎯 Objective  
To simplify the restaurant table reservation process through an easy-to-use web application that enhances customer convenience, minimizes manual effort, and helps restaurants manage reservations efficiently.
