# 🍽️ Reservé – Online Restaurant Table Reservation System

## 📖 Overview
**Reservé** is a web-based restaurant table and menu reservation system.  
It allows customers to explore restaurants, view menus, and reserve tables online, while restaurant administrators can efficiently manage bookings, approve requests, and update restaurant information through an integrated dashboard.  

---

## ⚙️ Key Features

### 👤 Customer Dashboard
- Secure registration and login.  
- Browse available restaurants and explore menus.  
- Reserve tables based on date, time, and number of guests.  
- View, modify, or cancel reservations easily.  

### 🧾 Admin Dashboard
- Manage and verify reservation requests.  
- Add, edit, or remove restaurant menus and details.  
- View daily and upcoming bookings through a clean interface.  

### 🔄 Reservation Flow
- Real-time table availability check.  
- Instant confirmation of successful bookings.  
- Notifications for booking status and updates.  

### 💾 Data Management
- All reservation data stored securely in a MySQL database (managed via phpMyAdmin).  
- Different access levels for admin and users to ensure data integrity.

| Layer             | Technology / Tool                     |

| Development Tools | Visual Studio Code, XAMPP (Localhost)|

---

## 🏗️ System Architecture
- **Frontend (Client Side):** Handles customer interaction and displays restaurant and menu details.  
- **Backend (Server Side):** PHP scripts process user requests, manage authentication, and communicate with the database.  
- **Database (MySQL via phpMyAdmin):** Stores users, restaurants, menus, and reservation records.  
- **Admin Panel:** Manages reservations, menu items, and restaurant data efficiently.  

---

## 🔒 Security & Validation
- Login authentication for both users and admins.  
- Validation of user input and booking details to prevent duplicate entries.  
- Restricted access to the admin dashboard to ensure data privacy and integrity.  

---

## 🎯 Objective
Simplify the restaurant table reservation process through an easy-to-use web application that enhances customer convenience, reduces manual effort, and helps restaurants manage reservations efficiently.
